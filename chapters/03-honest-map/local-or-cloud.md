# Local or cloud?

Glance at the matrix (ch03:45-55) before you hand a task to your local agent. It's a starting map, not a benchmark: tuning (chapter 8) and newer models move rows toward green.

| Task | Local handles this | Reach for cloud |
|---|---|---|
| Autocomplete and inline suggestions | green | |
| Boilerplate and scaffolding | green | |
| Single-file edits and small refactors | green | |
| Writing unit tests | green | |
| Explaining or documenting code | green | |
| Multi-file features | | amber |
| Large cross-file refactors | | amber |
| Long-context debugging | | amber |

The quick test: one file, a clear spec, fits in context? Green. Sprawling, cross-file, needs the whole system in view? Amber, so either use cloud for that one task or check every edit.
